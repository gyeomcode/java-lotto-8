# java-lotto-precourse

## 기능 목록

### 입력

- [ ] 로또 구입 금액을 입력받는다.
    - [ ] 문자열을 trim 처리한다.
    - [ ] 문자열을 숫자로 변환한다.

- [ ] 로또 구입 금액 입력을 예외 처리한다.
    - [ ] 숫자가 아닌 경우
    - [ ] 1,000원으로 나누어 떨어지지 않는 경우
    - [ ] 0 이하인 경우
    - [ ] Integer.MAX_VALUE를 초과한 경우

- [ ] 로또 번호(당첨 번호와 보너스 번호)를 입력받는다.
    - [ ] 로또 구입 금액만큼 반복한다.
    - [ ] 문자열을 trim 처리한다.
    - [ ] 당첨 번호는 쉼표를 기준으로 분리한다.
    - [ ] 각 번호를 숫자로 변환한다.

- [ ] 로또 번호 입력을 예외 처리한다.
    - [ ] 숫자가 아닌 경우
    - [ ] 0 이하인 경우
    - [ ] 45를 초과한 경우
    - [ ] 당첨 번호와 보너스 번호가 중복된 경우

- [ ] 입력받은 로또 번호를 오름차순 정렬한다.

- [ ] 발생한 예외를 처리한다.
    - [ ] `[ERROR]`로 시작하는 에러 메시지를 출력한다.
    - [ ] 해당 부분부터 입력을 다시 받는다.

### 로또 추첨

- [ ] 당첨 번호를 추첨한다.
    - [ ] 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.

- [ ] 당첨 내역을 계산한다.

- [ ] 수익률을 계산한다.
    - [ ] 소수점 둘째 자리에서 반올림한다.

### 출력

- [ ] 발행한 로또 수량 및 번호를 출력한다.

- [ ] 당첨 내역을 출력한다.

- [ ] 수익률을 출력한다.
